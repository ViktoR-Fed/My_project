# Проект - Улучшение личного кабинета клиента банка

## В этом проекте я делаю улучшения для личного кабинета клиента. Это виджет, который показывает несколько последних успешных банковских операций клиента. На бэкенде будем готовить данные для отображения в новом виджете.

## Функционал проекта.

### Модуль masks
Содержит функции для наложения масок на конфиденциальные данные:

**get_mask_card_number(card_number: Union[int, str]) -> str**

Маскирует номер банковской карты в формате: XXXX XX** **** XXXX
Пример: 7000792289606361 → 7000 79** **** 6361

**get_mask_account(account_number: Union[int, str]) -> str**

Маскирует номер счета в формате: **XXXX
**Пример:** 73654108430135874305 → **4305

### Модуль widget
Содержит функции для работы с банковскими данными:

**mask_account_card(account_card: str) -> str**

Автоматически определяет тип данных (карта или счет) и применяет соответствующую маску.
**Пример для карты:** Visa Platinum 7000792289606361 → Visa Platinum 7000 79** **** 6361
**Пример для счета:** Счет 73654108430135874305 → Счет **4305

**get_date(date: str) -> str**
Функция берёт данные даты и времени в формате "2024-03-11T02:26:18.671407"
и возвращает только дату в формате 'ДД.ММ.ГГГГ'"""

### Модуль processing
 Модуль processing предоставляет функции для фильтрации и сортировки банковских операций.

**filter_by_state(data: List[Dict[str, Any]], state: str = "EXECUTED") -> List[Dict[str, Any]]**
Фильтрует список операций по статусу выполнения.

**Параметры:**

#### data: Список словарей с операциями
#### state: Статус для фильтрации. По умолчанию 'EXECUTED'

**Пример использования:**
```
from processing import filter_by_state
data = [
    {'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
    {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}
    ]
# Фильтрация по статусу 'EXECUTED' (по умолчанию)
executed_operations = filter_by_state(data)
# [{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}]
# Фильтрация по статусу 'CANCELED'
canceled_operations = filter_by_state(data, 'CANCELED')
# [{'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}]
```
**sort_by_date(list_dict: List[Dict[str, Any]], ascending: bool = True) -> List[Dict[str, Any]]**
Сортирует список операций по дате.

**Параметры:**

#### showing: Список словарей с операциями
#### is_ascending: Порядок сортировки(True (по умолчанию) - по убыванию, False - по возрастанию(сначала самые старые))

Пример использования:
```
showing = [
    {'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
    {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}
]
# Сортировка по убыванию (сначала новые)
sorted_desc = sort_by_date(showing)
# [{'id': 41428829, ...}, {'id': 939719570, ...}]
# Сортировка по возрастанию (сначала старые)
sorted_asc = sort_by_date(showing,False)
# [{'id': 939719570, ...}, {'id': 41428829, ...}]
```

### Модуль generators
Модуль generators содержит функции для работы с массивами транзакций.

**filter_by_currency(transaction_list: List[Dict[str, Any]], currency_type: str) -> Any**

#### transaction_list: список словарей, представляющих транзакции.
#### currency_type: Валюта для фильтрации (например, USD).

**transaction_descriptions(transactions: List[Dict[str, Any]] | Any) -> Generator**

Функция - генератор, который принимает список словарей с транзакциями и возвращает описание каждой операции по очереди

**Параметры:**

#### transactions: список словарей, представляющих транзакции.

Пример использования:
```
descriptions = transaction_descriptions(transactions)
for _ in range(5):
    print(next(descriptions))

>>> Перевод организации
    Перевод со счета на счет
    Перевод со счета на счет
    Перевод с карты на карту
    Перевод организации
```

**card_number_generator(start: int, stop: int) -> Generator**

Функция - генератор, который выдает номера банковских карт в формате XXXX XXXX XXXX XXXX, где X — цифра номера карты

**Параметры:**

#### start: начальное значения для генерации диапазона номеров.
#### stop: конечное значения для генерации диапазона номеров.

Пример использования:
```
for card_number in card_number_generator(1, 5):
    print(card_number)

    0000 0000 0000 0003
    0000 0000 0000 0004
    0000 0000 0000 0005
```

### Модуль decorators
Модуль decorators содержит декораторы для автоматической регистрации деталей выполнения функции.

**log(filename=None):**

Декоратор, который будет автоматически логировать начало и конец выполнения функции,
а также ее результаты или возникшие ошибки.

**Параметры:**
#### filename: необязательный аргумент, который определяет, куда будут записываться логи (в файл или в консоль).

Пример использования:
```
@log()
def add_numbers(a, b):
    return a + b

add_numbers(1,2)

>>> Функция add_numbers начинает выполняться.

    add_numbers успешно выполнена. Результат: 3
```
